# Blink P0 视觉基线

- 状态：已选定并通过浏览器视觉验证
- 选定方向：Editorial Companion（视觉方案 3）
- 参考图：[blink-editorial-companion-success-pill.png](./assets/blink-editorial-companion-success-pill.png)

## 视觉语言

- 暖白页面、深海军蓝正文、陶土橙主操作、鼠尾草绿成功态、柔和金色恢复态。
- 注入 UI 使用固定 px 尺寸和 Shadow DOM，不继承宿主字体、变量或根字号。
- 胶囊位于输入框右下外侧 8px；空间不足时翻转到输入框上方并限制在视口内。
- 只在输入框聚焦或已有草稿时显示；不得遮挡发送、附件、语音等原站控件。
- 加载、相同结果、错误等普通反馈位于胶囊上方；恢复卡持续存在，直到恢复、复制或页面离开。
- 优化成功不新增反馈浮层，当前胶囊原地切换为 `[✓ 已优化] [撤销]`。

## 必须实现的状态

1. Ready：分体胶囊 `Blink / 当前模式`。
2. MenuOpen：自动、精简、专业及自定义模式。
3. Loading：正在优化，主操作与模式选择禁用。
4. SameResult：当前表达已经足够清晰。
5. Success：原胶囊变为 `[✓ 已优化] [撤销]`，不显示模式选择或第二个成功浮层。
6. Error：安全错误文案；设置类错误带打开设置。
7. Recovery：无法恢复原文、恢复输入框、复制原文。

## 设置页

- 顶部/左侧显示模型配置、站点授权、就绪状态检查清单。
- 主内容严格为模型服务、优化模式、支持站点三个区域。
- “清除模型服务”只删除 Provider；“重置 Blink”删除全部配置、权限和动态脚本。
- 中文与英文共用布局；其他 Chrome UI 语言回退英文。

## 无障碍

- 正文不小于 14px；200% 缩放不截断主要操作。
- 模式菜单使用 `menuitemradio`，支持方向键、Enter、Escape。
- 普通反馈使用 `aria-live=polite`，恢复失败使用 `role=alert`。
- 所有交互具备清晰 `:focus-visible` 样式；减少动态效果时禁用非必要动画。
